Documentación y Detalles del Sistema

Sobre el Proyecto

ZEUS APEX es un sistema domótico de monitoreo y control remoto en tiempo real diseñado para entornos residenciales o de oficina.

El objetivo principal es brindar control de iluminación y supervisión de accesos y seguridad mediante la nube, permitiendo la interacción desde cualquier dispositivo web.

¿Cómo Funciona?
  • Procesamiento: Una tarjeta de desarrollo (ESP32 / ESP8266) procesa las lecturas físicas de los sensores.
  • Comunicación Nube: El microcontrolador transmite datos de forma bidireccional hacia Firebase Realtime Database a través de Wi-Fi.
  • Interfaz Web: El Dashboard lee en tiempo real el estado de la base de datos usando JavaScript y WebSocket.
Componentes Utilizados
  • Sensor KY-021: Interruptor magnético (Reed Switch) para detectar la apertura o cierre de puertas.
  • Sensor SR505: Sensor infrarrojo pasivo (PIR) para la detección de presencia o movimiento humano.
  • Módulo Relé: Actuador electromecánico para controlar el encendido/apagado de las luces de potencia.
  • Servidor Web & Nube: Google Firebase RTDB e Interfaz Responsive HTML5/CSS3.
